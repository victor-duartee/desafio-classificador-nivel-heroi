# 🦸 Classificador de Nível de Herói

Projeto desenvolvido durante a **Formação Lógica de Programação** da [DIO](https://www.dio.me/).

O desafio consiste em criar um classificador capaz de determinar o nível de um herói de acordo com a quantidade de XP (experiência) informada.

## 🎯 Objetivo

Criar um programa que armazene o **nome** e a **quantidade de XP** de um herói e, utilizando estruturas de decisão, determine seu nível.

## 📊 Classificação

| XP | Nível |
|---|---|
| Menor que 1.000 | Ferro |
| 1.001 a 2.000 | Bronze |
| 2.001 a 5.000 | Prata |
| 5.001 a 7.000 | Ouro |
| 7.001 a 8.000 | Platina |
| 8.001 a 9.000 | Ascendente |
| 9.001 a 10.000 | Imortal |
| Maior ou igual a 10.001 | Radiante |

## 🛠️ Tecnologias e conceitos utilizados

- JavaScript
- Visual Studio Code
- Variáveis
- Operadores
- Estruturas condicionais (`if`, `else if`, `else`)
- Laços de repetição

## 💻 Funcionamento

O programa recebe o nome e a quantidade de XP do herói e verifica em qual faixa de experiência ele se encontra.

Ao final, exibe uma mensagem informando o nome e o nível do herói.

### Exemplo de saída

```text
O Herói de nome Vitinho está no nível de radiante
```
